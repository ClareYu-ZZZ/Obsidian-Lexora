# Lexora Pro 与订阅

Lexora 是 open-core：仓库代码 MIT 开源，**免费版永久可用**。

## 免费版包含

- 订阅管理、文章 / 带字幕媒体的教程生成（**每月 10 篇**）
- 自建词库（1.1 万词）+ 例句库、高亮、悬停词卡、词本
- 欧路词典双向同步
- FSRS / SM-2 / Leitner 复习，4 种基础模式
- 播放器（区间播放、跟读录音）、统计打卡

## 订阅与激活

- 购买后获得形如 `LEXORA1.…` 的 license key
- **设置 → Lexora Pro → License key** 粘贴 → 应用，状态行显示到期日期
- key 为离线 Ed25519 签名校验：无账号、不回传数据；key 随 vault 同步，**至多激活 3 台设备**（worker 侧校验，防止 key 外借分发）

## 试用

首次触发任意 Pro 功能时自动开始 **3 天全功能试用**：Pro 功能全开 + worker 原声转写累计 3 次。试用绑定开始时的那台设备（免费档限 1 台设备），到期自动回到免费版，数据不受影响。
